# Homebrew tap for Doppel

[Doppel](https://github.com/roushou/doppel): isolated macOS machines for AI agents.

```sh
brew install roushou/doppel/doppel
doppel setup
```

Apple silicon only. The formula installs the signed, notarized release from
[roushou/doppel's releases](https://github.com/roushou/doppel/releases).
